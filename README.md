# Water Quality Monitoring Mobile Application

A **React Native mobile application** developed to make water quality monitoring more **accessible, intuitive, and easy to visualize from anywhere**.

The application provides a user-friendly interface for monitoring and visualizing water quality data collected by an IoT-based monitoring system. It allows users to access measurements remotely and better understand the water conditions through clear and interactive visualizations.

### Main Objectives

* 📊 **Visualize water quality data** in a simple and intuitive way.
* 🌍 **Access monitoring data remotely** from anywhere.
* 📱 Provide a **cross-platform mobile application** using React Native.
* 🔔 Facilitate the monitoring of important water quality parameters.
* 🐟 Support **aquaculture and fish farming monitoring** by providing an overview of water conditions.

### Monitored Parameters

The application can display data such as:

* pH
* Temperature
* Turbidity
* Dissolved Oxygen (DO)
* Water quality status

### System Architecture

The mobile application is part of a complete **IoT-based water quality monitoring system**, where sensors collect environmental data, an embedded system processes the measurements, and the data is transmitted to a backend platform for storage and visualization.

**Technologies:** React Native · JavaScript · IoT · Embedded Systems · MQTT · REST API
